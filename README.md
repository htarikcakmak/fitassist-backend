# FitAssist - Backend API

This repository contains the backend services and database management for the FitAssist application. Built with Java and Spring Boot, it provides robust RESTful APIs to track fitness goals, nutrition, and sleep logs.

## Features
- **Sleep Tracking API:** Endpoints to log, store, and retrieve daily sleep durations.
- **Nutrition & Workout Management:** Database operations for tracking meals, macros, and exercise routines.
- **RESTful Architecture:** Clean, scalable, and modular endpoint design.

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- Cross-Origin Resource Sharing (CORS) configured for React Frontend
